SMRITI PORTAL - HOW TO PUT IT ON THE INTERNET (no coding needed)

This folder has NO hidden files, so a normal drag-and-drop upload works.

STEP 1  Create the repository (skip if you already have one)
  github.com -> "+" (top right) -> New repository -> name it, e.g. Smriti-portal -> Create repository.

STEP 2  Upload the files
  Open the repository -> "uploading an existing file" (or Add file -> Upload files).
  Open this folder, press Ctrl+A to select EVERYTHING inside it (index.html, css, js, img, data, scripts, ...)
  and drag it all into the browser. Wait until all files show, then click "Commit changes".
  Tip: the page "index.html" must be visible directly in the repository's main list (not inside another folder).

STEP 3  Turn on the website
  Repository -> Settings -> Pages (left menu).
  Under "Build and deployment" -> Source: choose "Deploy from a branch".
  Branch: choose "main", folder "/ (root)" -> Save.
  Wait 2 minutes, refresh. The website address appears at the top of that page.
